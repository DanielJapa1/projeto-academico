# Projeto Acadêmico

## 📖 Sobre
Sistema simples para organização de informações acadêmicas, desenvolvido como parte da disciplina de **Desenvolvimento Web**.

## ✨ Funcionalidades
- Interface limpa e responsiva
- Estrutura semântica HTML5
- Estilos modernos com CSS3 (variáveis, flexbox)
- Controle de versão com Git e GitHub

## 🛠 Tecnologias
- HTML5
- CSS3
- Git / GitHub

## 🚀 Como Executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/DanielJapa1/projeto-academico.git
   ```
2. Abra o arquivo `index.html` no navegador.
